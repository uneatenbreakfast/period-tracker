### BLOOM-0026 — Month-tint SVG drifts off cells on some phone viewports
On certain Android Chrome viewports the odd-month lavender SVG tint (`monthBackgroundPaths`) sits ~0.5 row below its cells and ends ~1 row short — visible as a white band above each date and a missing strip at the bottom of the tinted month. The root cause: the SVG is absolutely positioned inside a `relative` height-auto wrapper with `h-full w-full`; when the browser's percentage-height resolution falls back to the intrinsic 7:36 ratio (rather than resolving 100% of the wrapper), the SVG's per-row unit becomes `svgWidth / 7` instead of the actual cell pitch, which drifts progressively down the strip (earlier months near the top of the viewBox = aligned; later months = shifted). Fix: measure the wrapper's real bounding box via ResizeObserver and set the SVG's explicit `width`/`height` in px — the overlay now tracks the rows exactly, and the fallback `h-full w-full` class still covers the single frame before measurement. Verified: 0 drift rows at every tested viewport (phone 345×251 DPR3.166, 448×325 DPR2.44, desktop 1280×720); build + tsc clean. Completed 2026-09-06.

Follow-up 2026-09-06 — measured-px box size was NOT enough: rows are NOT uniformly pitched on every device because month-start labels, Android font scaling (accessibility), zoom, and narrow widths grow SOME rows taller. The old fix sized the SVG box correctly but the paths still mapped rows as equal units (viewBox `0 0 7 N`), so on uneven grids the tint drifted again. Root cause of follow-up: uniform-row assumption in `monthBackgroundPaths`. Real fix: the component now measures EVERY week row's rect (ResizeObserver on wrapper + each row) and passes `MonthGeom {cellW, rowTops, rowHeights}` — paths are generated in PIXEL space (viewBox `0 0 W H`, identity map), so the tint lands exactly on the measured cells at ANY screen size/DPR/font scale/zoom. Legacy no-geom call (unit grid, viewBox `0 0 7 N`) retained for tests + pre-measure fallback. Verified: 9 stress cases × 4 tint paths: narrow 280px, 375, font 120/150/200%, font-150 on 320px, DPR3, landscape, desktop — ALL dTop/dBot = 0.00px (frame-consistent getBBox vs row rects). Real browser zoom 125%/80% (CDP pageScaleFactor) + viewport resize also 0.00px. 6 new unit tests in `monthTint.test.ts` (legacy exact output, px uniform, px non-uniform 2-row, px non-uniform 3-row, geom-length mismatch fallback). 265 tests green + tsc clean + build green.

Completed 2026-09-06.
